# Desire · 韩国被封锁网站分类查询站

基于 [wpzzz/blocked-sites-in-south-korea](https://github.com/wpzzz/blocked-sites-in-south-korea) 仓库（`kr.list` + `list.txt`，去重 2805 个域名）的批量分类结果，做成的静态查询网站。

## 分类方法（四轮）

1. **域名启发式** — 多语言关键词库 + 知名品牌名单，四轮迭代补回漏网品牌词
2. **首页标题抓取** — 2120 个目标拿到 1634 个 HTTP 200、1546 个页面标题，约 90 条标题证据直接修正分类
3. **urlscan 补全** — 对 202 个抓取失败的域名用 urlscan.io 历史扫描记录补全
4. **疑难核验** — 搜索引擎逐个核验疑难域名
